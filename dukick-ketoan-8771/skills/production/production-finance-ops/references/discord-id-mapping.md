## Cách dùng trong cronjob / message

Tag bằng format: `<@USER_ID>`
- Ví dụ: `<@885170747797032991>` sẽ tag Yến
- Ví dụ: `<@1338069800240549898>` sẽ tag Huyền

Khi ID chưa có, ghi rõ tên trong text thay vì tag chung chung (không dùng `@PM` hay `@Kế toán` vì sẽ không đi đến đúng người).

## How to get a Discord User ID

1. Discord Settings → Advanced → bật **Developer Mode**
2. Right-click tên người trong server / DM → **Copy User ID**
3. Paste vào bảng này

## When to update
- Mỗi khi có nhân sự mới vào team
- Mỗi khi thay đổi vai trò (ví dụ: Huyền chuyển sang Kế toán)

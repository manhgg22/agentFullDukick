---

## Rules when filling this template

1. **Keep to ≤3 questions** — if more than 3, split into separate reminders or a meeting request.
2. **Each option must be binary A/B** — avoid open-ended "chị nghĩ sao" questions.
3. **Always include:**
   - Reference to the original commitment (date, context).
   - Current status of existing rules (what's already decided vs what's pending).
   - Why the deadline matters (what's blocked until chị decides).
4. **Tone:** Polite, urgent but not panicked. Use 🌷 emoji for Leo. End with explicit call-to-action.
5. **After chị replies:** Update the vault tracking file immediately, then announce in #agent-mẹ.

# Framework: Phát triển Creative Direction TVC từ Reference

## When to Use
- Có brief + brand pillars + 2-5 reference videos từ khách.
- Cần đề xuất ≥2 hướng sáng tạo khác biệt để pitch.
- Khách chưa có concept — cần dẫn dắt bằng insight.

## 3-Axis Creative Direction Generator

Từ brief + brand pillars, generate directions bằng cách kết hợp các axis:

| Axis A: Narrative Driver | Axis B: Visual Approach | Axis C: Emotional Core |
|---------------------------|------------------------|------------------------|
| **Journey** (1 protagonist, linear time) | **Cinematic** (shallow DOF, golden hour, smooth) | **Aspiration** (dreams, future, growth) |
| **Mosaic** (multi-protagonist, moments) | **Documentary** (handheld, candid, natural light) | **Belonging** (community, warmth, care) |
| **Dialogue** (QA, interview, voice-led) | **Artistic** (color-coded, stylized, graphic) | **Pride** (achievement, recognition, legacy) |
| **Poetic** (metaphor, symbolism, abstract) | **Dynamic** (fast cuts, motion, energy) | **Wonder** (curiosity, discovery, possibility) |

**Formula:** Chọn 1 từ mỗi axis → 1 direction. Lặp lại để có 3 directions.

## Decision Guide

| Khách nói gì | Direction phù hợp |
|--------------|-------------------|
| "Em muốn safe, dễ làm" | Mosaic + Documentary + Belonging (Direction 2: A Day in Color) |
| "Em muốn viral, khác biệt" | Dialogue + Cinematic + Aspiration (Direction 3: The Conversation) |
| "Em muốn rõ pathway, academic" | Journey + Cinematic + Pride (Direction 1: The Path) |
| "Em có 3 tier budget" | Tier 1 = Mosaic / Tier 2 = Journey / Tier 3 = Dialogue |

## Pitfalls
- **Đừng copy reference.** Reference = ngôn ngữ chung với khách, không phải template để clone.
- **Đừng bỏ brand pillars.** Mỗi direction PHẢI map rõ cả 3 pillar.
- **Đừng quên format cuts.** Client cần master + cutdowns + social từ ngày đầu.
- **Đừng đề xuất direction cần cast khó nếu chưa rõ budget.** "The Conversation" cần diễn xuất tốt = casting premium.
